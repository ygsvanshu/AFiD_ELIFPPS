# `global.out`

The ascii file consists of global flow statistics as a time series. The columns of the data are explained as follows.

1.  `Time`: Nondimensional flow time

2.  `Max_Vx`: The maximum absolute value of x-component of nondimensional velocity in the domain
3.  `Max_Vy`: The maximum absolute value of y-component of nondimensional velocity in the domain
4.  `Max_Vz`: The maximum absolute value of z-component of nondimensional velocity in the domain

5.  `Avg_Vx`: The value of spatially averaged x-component of nondimensional velocity over the domain
6.  `Avg_Vy`: The value of spatially averaged y-component of nondimensional velocity over the domain
7.  `Avg_Vz`: The value of spatially averaged z-component of nondimensional velocity over the domain

8.  `RMS_Vx`: The value of root mean squared (RMS) x-component of nondimensional velocity over the domain
9.  `RMS_Vy`: The value of root mean squared (RMS) y-component of nondimensional velocity over the domain
10. `RMS_Vz`: The value of root mean squared (RMS) z-component of nondimensional velocity over the domain

11. `RMS_VxVyVz`: The average value of nondimensional velocity magnitude in the domain
